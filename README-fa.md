# شیفتالو

شیفتالو یک اپ اندرویدی فارسی، آفلاین و بدون حساب کاربری برای مدیریت شیفت‌های بیمارستانی است. برنامه مجوز اینترنت ندارد و همهٔ اطلاعات در پایگاه دادهٔ محلی خود گوشی ذخیره می‌شود.

## امکانات نسخهٔ ۱

- تقویم واقعی شمسی با ماه‌های جلالی و تعطیلات رسمی بسته‌بندی‌شدهٔ سال ۱۴۰۵
- ثبت روزکار، عصرکار و شب‌کار بدون الگوی تکرار
- زنگ واقعی گوشی با صفحهٔ تمام‌صفحه، صدا و لرزش
- تنظیم دوبارهٔ زنگ‌ها پس از روشن شدن گوشی
- اعلام دقیق تداخل با نام نوع شیفت، بیمارستان، تاریخ و ساعت
- فهرست روزانه و فیلتر ماه، بیمارستان، نوع شیفت و وضعیت پرداخت
- تعریف حقوق پایه و نرخ جداگانهٔ هر نوع شیفت برای هر بیمارستان
- استفادهٔ خودکار از نرخ بیمارستان وقتی مبلغ اختصاصی شیفت خالی است
- محاسبهٔ حقوق تقریبی ماه و تفکیک درآمد هر بیمارستان
- نمودار تعداد شیفت و درآمد ماه جاری و پنج ماه آینده
- ویجت صفحهٔ اصلی برای نمایش شیفت‌های آینده
- نمایش اعداد فارسی بدون جداکنندهٔ هزارگان

## حریم خصوصی و آفلاین بودن

در `AndroidManifest.xml` هیچ مجوز اینترنتی تعریف نشده است. پایگاه داده، تقویم و فهرست تعطیلات همگی داخل برنامه هستند. برای هشدار، فقط مجوز اعلان، زنگ دقیق، لرزش و اجرای دوباره پس از روشن‌شدن گوشی درخواست می‌شود.

## ساخت APK

در GitHub از بخش Actions گردش‌کار «ساخت APK شیفتالو» را اجرا کنید. فایل نصب‌شونده با نام `Shiftaloo.apk` در Artifact همان اجرا قرار می‌گیرد.

برای ساخت محلی به Android SDK 35، Java 17 و Gradle 8.9 نیاز است:

```bash
gradle :app:assembleDebug
```
